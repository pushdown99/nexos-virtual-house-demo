# NexOS Care 가상 중간집 3D 데모

실제 중간집 평면도와 관제 스냅샷을 반영한 Three.js 기반 브라우저 3D 데모입니다.

배포 주소: [house3d.nexoscare.com](https://house3d.nexoscare.com)

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 엽니다. 프로덕션 결과물은 `npm run build`로 `dist/`에 생성됩니다.

## 포함 기능

- 중간집 1~4, 화장실, 현관, 복도, 돌봄인력공간, 주방, 간호사실, 작업치료실, 커뮤니티실, 사무공간, 테라스 3D 평면
- 도면에 표시된 설치기기 10대 위치 시각화
- 전체 8명, 침실 재실 5명, 방 밖 3명, 화장실 0명의 관제 스냅샷 표현
- 방별 조명 켜짐·꺼짐 시각화
- 공간 선택 및 카메라 이동
- 키보드/모바일 이동 조작
- 공간별 센서·안심 정보 패널
- 반응형 시니어 친화 UI
- 생활 소리 토글과 공간 상세 설명

## 확인

개발 서버를 실행한 상태에서 아래 명령으로 데스크톱·모바일 화면과 공간 전환을 자동 확인합니다.

```bash
npm run test:smoke
```

현재 관제 정보는 확인 시점의 스냅샷이며 실시간 API와 연결하지 않습니다. 공간 비율과 기기 위치는 제공된 개념 도면을 시각적으로 옮긴 것으로, 시공용 치수 모델이 아닙니다.
